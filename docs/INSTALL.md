# AC8 MOD 1.0 安装说明

1. 将完整安装包解压到游戏目录以外的位置，不要在 ZIP 内直接运行。
2. 双击文件夹中的 **AC8Workbench.exe**。
3. 在“安装与启动”中选择游戏位置、Steam 程序和安装方案，点击左下角“保存设置”。
4. 第一次使用或移动文件夹后，复制页面中的启动选项，粘贴到 **Steam → 游戏属性 → 通用 → 启动选项**。
5. 点击右下角“开始游戏”。默认勾选“从 Steam 启动”，由 Steam 先处理云同步，再启动 MOD 会话。

取消“从 Steam 启动”后，使用原 MOD 的直接会话启动流程；Steam 仍须已运行。首次安装建议保留默认勾选项。
游戏退出后，原有归属校验、备份及清理流程会自动执行。异常退出可在“模组管理”中清理和恢复。

## 选择安装内容

| 安装方案 | 内容 |
|---|---|
| 飞控 + 仅比例引导 | 鼠标飞控与导弹引导，保留原版导弹性能 |
| 飞控 + 完整导弹强化 | 鼠标飞控与原 MOD 完整导弹模块 |
| 仅鼠标飞控 | 鼠标飞控，保留原版导弹 |

更改安装方案前退出游戏，修改后下次启动应用。

## 更新与文件夹

EXE 是启动与设置入口。请保留旁边的 payload、runtime、配置与脚本；发布和复制时需要整个文件夹。
移动文件夹后重新保存安装设置，并替换 Steam 启动选项。不要同时使用多个安装包启动同一游戏。
本包沿用原 MOD 适配要求：Windows x64，游戏 Build 25201480。启动前会检查游戏版本和已有加载器的归属。

## 设置保存

EXE 中的设置在下次启动时应用。游戏内实际调整过的灵敏度、自由观察缩放、PEACE/WAR、机外相机模式及机头十字会自动保存到这个 MOD 文件夹。
工具保持打开时会自动读取这些变化；同一项目的游戏内调整优先，其他未保存的菜单调整保留。保存前会建立设置备份。

## 修改外置资源

INI 设置可直接修改。修改 payload 资源后运行 Update-Resources.cmd 更新校验；修改 C++ 则重编 DLL 后更新校验。
更改资源无需把 MOD 重新打包进 EXE。许可证、原作者署名与来源记录保留在 LICENSE、THIRD_PARTY_NOTICES.md 和 source 中。
